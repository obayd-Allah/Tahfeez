# مشروع التحفيظ — Tahfeez

مشروع ويب مستقل للتحفيظ، مصمم ليكون أساسًا مشتركًا لفكرة التحفيظ في الموقع والتطبيق.

## الوضع العادي
يُشغّل تسجيل الشيخ فقط.

## وضع الشيخ المعلم
يستخدم تسجيلين متطابقين زمنيًا:
- `teacher` = تسجيل الشيخ.
- `child` = التسجيل بصوت الطفل.

وعند وجود مصفوفة وقفات للآية، ينتقل المحرك بالتناوب:
الشيخ → الطفل → الشيخ → الطفل ...

## مصفوفة الوقفات
توضع في:
`data/pause-points.js`

مثال:
```js
const PAUSE_POINTS = {
  4: [3.42, 7.81, 12.56],
  5: [2.91, 6.73]
};
```

القيم هي ثوانٍ داخل تسجيل الآية.

## ملفات الصوت
الصيغة الافتراضية:
`audio/minshawi-muallim/017-004-teacher.mp3`
`audio/minshawi-muallim/017-004-child.mp3`

غيّر `makeAudioPath()` في `js/player.js` إذا كان تنظيم الملفات مختلفًا.

## ملاحظات
- لا يوجد Seek Bar.
- زر ▶️/⏸️ واحد: أثناء التشغيل يوقف الآية، وعند تشغيلها مرة أخرى يعيد الآية الحالية من بدايتها.
- 🛑 الإيقاف الدائم يعيد الآية والفقرة والتكرارات كلها إلى البداية، حتى لو كانت الجلسة في التكرار 7 من 10.
- شريطان مرئيان للتقدم: تكرار الآية وتكرار الفقرة.
- نصوص القرآن ستربط بمصدر موثوق في مرحلة لاحقة.
